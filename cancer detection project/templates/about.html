SYSTEM INFORMATION

Transparent by design.

Processing pipeline

OncoMetric uses the Breast Cancer Wisconsin Diagnostic dataset, a training-only StandardScaler, a Logistic Regression benchmark, and a TensorFlow/Keras feed-forward neural network. The prediction service uses the saved model and feature order produced by the training pipeline.

Model governance

Inputs are validated for completeness, numeric type, expected length, and finite values. Performance metrics are generated from a held-out test set and displayed only when actual artifacts exist.

LIMITATIONS

Use with care.

The dataset is limited and historical. The model has not been clinically validated, calibrated for patient risk, or approved for diagnosis or treatment decisions.
