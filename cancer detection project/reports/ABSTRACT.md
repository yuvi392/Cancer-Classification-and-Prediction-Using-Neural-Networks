# Abstract

This project demonstrates binary classification of breast-tumor measurements using the Breast Cancer Wisconsin Diagnostic dataset. A leakage-safe preprocessing pipeline, Logistic Regression baseline, and feed-forward neural network are implemented and evaluated with clinically relevant classification measures. A Flask interface accepts the 30 measurements and presents an educational model output. Results are generated from the held-out test set; no performance value is claimed in advance. This system is not a medical diagnosis tool.
